# هيكل التقرير (Binding Report Structure)

> اللغة: **عربية تنفيذية واضحة** · الاتجاه: **من اليمين إلى اليسار (RTL)** · الأرقام: **إنجليزية (0-9)** · معالجة صحيحة للمصطلحات الإنجليزية المضمّنة (bidi).
> This structure is binding. Both the PDF and the Word export must follow it exactly.

---

## 1. الملخص التنفيذي (Executive Summary)

يتضمن العناصر التالية:

- اسم المقرر ورمزه.
- نطاق المراجعة.
- الملفات التي أمكن فحصها.
- الملفات التي تعذّر فحصها.
- نسبة الجاهزية الإجمالية (٪).
- مستوى التوافق مع QM.
- مستوى التوافق مع NELC.
- مستوى جودة المحتوى.
- مستوى الوصول وسهولة الاستخدام.
- حالة السلامة الدينية والسياسية والثقافية.
- عدد الملاحظات: حرجة / عالية / متوسطة / منخفضة.
- الحكم النهائي.

## 2. الحكم النهائي (Final Verdict)

يُختار **حكم واحد فقط** من الخمسة:

| الرمز (code) | النص العربي |
|---|---|
| `READY` | جاهز للنشر |
| `READY_LIMITED_FIXES` | جاهز بعد تحسينات محدودة |
| `NEEDS_SUBSTANTIAL_REVISION` | يحتاج تعديلات جوهرية قبل النشر |
| `NOT_READY` | غير جاهز للنشر |
| `INCOMPLETE_EVIDENCE` | تعذر إصدار حكم مكتمل بسبب نقص الأدلة |

---

## ملاحظات التنفيذ (Implementation notes)

- الحكم النهائي وحالة السلامة الدينية/السياسية/الثقافية **لا يصدران آلياً** — يُعرضان للمراجع، ويُعتمدان بعد التوقيع البشري (sign-off) فقط.
- كل ملاحظة (Finding) تحمل: الإطار (QM/NELC/محتوى/وصول/سلامة) · الشدة · الوصف · التوصية · الموقع (ملف/صفحة).
- الملفات غير القابلة للفحص (فيديو/صوت/بعض كائنات SCORM) تُدرَج صراحةً تحت «الملفات التي تعذّر فحصها» مع السبب — لا تُحتسب كناجحة.
